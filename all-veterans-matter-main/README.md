# All Veterans Matter

All Veterans Matter is a deploy-ready Next.js MVP landing page focused on
connecting veterans, transitioning service members, military families, and
caregivers with trusted resources nationwide.

## Mission

No Veteran Left Behind.

## Tech Stack

- Next.js App Router
- Tailwind CSS
- TypeScript
- ESLint

## Homepage Sections

- Hero section with dual calls to action
- Resource categories
- Mission overview
- Featured organizations
- Success stories
- Footer

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000` to view the site locally.

## Production

```bash
npm run build
npm start
```
